A propos

Hébergement Web


1- Service de stockage de sites internet sur des serveurs afin qu'ils soient accessibles sur le web.

2- Accessible pour les utilisateurs sur un site web.

3- Transfert de fichiers (textes, images, vidéos) au serveur via un navigateur pour l'usage client.

Communication Réseau


1- Partage des données entre différents appareils interconnectés. (imprimantes, ordinateurs, box,)

2- Partage d'informations, de ressources et de services via des protocoles de communication.

3- Réseau local : interne ou à distance (connexions filaires ou sans fil selon l'infrastructure.)
