A propos



Communication Réseau



1. Introduction



Un réseau :

* Ensemble d’éléments reliés les uns aux autres et entre lesquels circulent des informations.

* Construit autour d’un serveur qui gère un certain nombre de services.

2 - Role du serveur :



* Partage de fichiers, communication entre personnes (courrier électronique, la discussion en direct).

* Communication entre processus (entre des machines industrielles).

* Unicité de l’information (base de données).

3. L’architecture du réseau



1- La communication réseau est organisé à partir d’un grand nombre d’éléments matériels parmi lesquels :

• Postes de travail : ordinateurs reliés au réseau ;

• Serveurs sont des ordinateurs qui fournissent des ressources partagées aux utilisateurs ;

• Commutateur : élément d’interconnexion de deux segments de réseaux locaux ;

• Modem : périphérique de conversion qui assure la connexion à Internet ;

2- Un réseau comprend différents composants matériels parmi lesquels :

• la carte réseau : connectée sur la carte mère de l’ordinateur ;

• la prise : réalisant la jonction entre la carte réseau et le support physique d’interconnexion ;

• le support physique d’interconnexion : reliant les ordinateurs entre eux (câble, système wifi…) ;

• la passerelle : reliant des types différents de réseaux locaux ;

• le routeur : outil logiciel ou matériel pour diriger les données à travers un réseau. Le routeur est ausso une interface entre deux réseaux utilisant des protocoles différents.

4. Les protocoles de communication



Un protocole : Règles et de procédures à respecter pour permettre la communication entre plusieurs ordinateurs qui échangent des données.

Les principaux protocoles réseaux sur Internet sont :

TCP/IP : protocole de communication qui permet de relier des machines entre elles ;

HTTP : protocole utilisé pour transférer des documents hypertextes entre un serveur web et un client web ;

IP : nom servant à identifier un ordinateur connecté à un réseau ;

FTP: permet de transférer des fichiers.

Conclusion :


- La communication sur un réseaux :

1 - Organisation à partir d’éléments matériels permettant d’établir les communications et d'assurer les transferts d’informations.

2- la possibilité de mettre en relation différents éléments informatiques pour se connecter par les machines.

3- la diffusion de toutes sortes d’informations.
